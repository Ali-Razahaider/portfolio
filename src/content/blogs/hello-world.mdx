Welcome to my brand new blog! 

Since I'm a developer, I wanted a blogging system that feels native to how I work. Instead of using a clunky CMS or dealing with database queries, this blog is powered entirely by **MDX** (Markdown + JSX).

### Why MDX?

1. **Lightning Fast:** Because it's completely static, these pages load instantly.
2. **Developer Friendly:** I can just write standard Markdown directly in my code editor and push to GitHub to publish.
3. **Custom Components:** I can even inject React components directly into my markdown if I want interactive charts or code playgrounds later!
